# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Раздел версии целиком уходит в описание релиза на GitHub (`.github/workflows/release.yml`).

## [1.0.0] — 2026-10-31

Первый релиз: сервер со всеми инструментами из ТЗ, развёрнут на prod.

### Сервер
- 21 инструмент MCP: открытые данные (группы, расписание группы и преподавателя), вход и выход в ЛК,
  личный кабинет (профиль, расписание, успеваемость, уведомления, платежи, заявки, диалоги, отправка
  сообщений), история изменений, отслеживаемые группы — описание в `docs/tools.md`.
- Вход по `lk_login` или странице `/login`: пароль не сохраняется, токены ЛК зашифрованы, доступ —
  по персональному ключу `mpk_…`.
- Кэш с откатом на него при недоступности источника, журнал обращений к ЛК, `/health`.
- Отслеживаемые группы привязаны к пользователю по `user_id` с внешним ключом на `users`.

### База данных
- 8 миграций Alembic, снимок схемы — `db/schema/schema.sql`, описание — `docs/db-schema.md`.
- Миграции без долгих блокировок: `CONCURRENTLY`, `NOT VALID` + `VALIDATE`, `lock_timeout`.

### Сборка и доставка
- CI: ruff, bandit, gitleaks, squawk → сборка образа → тесты с PostgreSQL → образ в GHCR.
- Деплой на stage после `dev` и на prod после `main` с ручным одобрением: резервная копия БД, миграция,
  сверка схем стендов, `/health`.
- Образ `ghcr.io/edeev/mospolytech-mcp:1.0.0`, пакет (wheel, sdist) — в релизе.
