# Документация проекта

Делим на три вида, чтобы не путаться:

- **Техническая документация** (ТЗ, раздел 7) — Markdown рядом с этим файлом: что умеет сервер, как устроена
  БД. Обновляется вместе с кодом, в том же pull request.
- **`official/`** — официальные документы, которые сдаём преподавателю: ТЗ и отчёты по лабораторным, PDF по
  ГОСТ. Сданное не правим — следующая лабораторная идёт новым файлом.
- **`working/`** — рабочие записи команды: план по лабораторным, риски, черновики. Правим постоянно, это не
  для сдачи, а чтобы не терять контекст между лабораторными.

`sdo/` — методички по всем 8 лабораторным и справочные ГОСТ/IEEE из СДО, как их выдали.
