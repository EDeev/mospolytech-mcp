# Документация проекта

Делим на два вида, чтобы не путаться:

- **`official/`** — официальные бумажки, которые сдаём преподавателю по
  каждой лабораторной, в формате PDF, оформленные по ГОСТ (как и требует
  ТЗ, раздел 7). Мы их не правим "по ходу дела" — раз сдали, значит,
  зафиксировали. Следующая лабораторная — новый файл.
- **`working/`** — наши рабочие записи для себя: план, заметки по рискам,
  черновик схемы БД и т.п. Эти документы мы правим постоянно, они не для
  сдачи, а чтобы не терять контекст между лабораторными и держать в одном
  месте то, что иначе разошлось бы по трём головам.

Технической документации к коду (описание MCP-инструментов, схема БД,
инструкция по развёртыванию — как требует ТЗ, раздел 7) тоже место здесь,
в Markdown, по мере появления соответствующего кода.
