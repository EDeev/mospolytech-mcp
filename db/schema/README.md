# Актуальная схема БД

`schema.sql` — текущая схема базы данных PostgreSQL сервера (таблицы, последовательности, ограничения, индексы)
после применения всех миграций Alembic из `alembic/versions/`. Это выгрузка стандартным инструментом PostgreSQL
`pg_dump --schema-only` (без владельцев и прав доступа, без данных).

Файл не применяется к БД: схему создают и меняют только миграции. Он нужен, чтобы схему можно было прочитать целиком
в одном месте и чтобы в каждом изменении схемы diff этого файла наглядно показывал, что именно изменилось.

## Как получить

Скриптом `scripts/dump_schema.sh` из корня репозитория, когда стек `docker compose` запущен и миграции применены
(контейнер сервера выполняет `alembic upgrade head` при старте):

```sh
docker compose up -d
scripts/dump_schema.sh > db/schema/schema.sql
```

Скрипт вызывает `pg_dump --schema-only --no-owner --no-privileges` в контейнере `db` и убирает из вывода
строки-комментарии, строки `\restrict`/`\unrestrict` (pg_dump 17.6+ пишет в них случайный ключ при каждом запуске)
и лишние пустые строки — две выгрузки одинаковых схем совпадают побайтно.

## Когда обновлять

Вместе с каждой миграцией: в том же коммите, что и новый файл в `alembic/versions/`, — выгрузка БД, к которой
применена эта миграция (`alembic upgrade head`).
