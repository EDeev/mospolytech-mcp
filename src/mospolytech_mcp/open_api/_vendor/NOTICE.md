# Откуда это

`api.py` и `schedule.py` в этой папке — код библиотеки
[mospolytech_api](https://github.com/r4nd0lph-c/mospolytech_api)
(автор — r4nd0lph-c), скопированный сюда как есть, без правок. Так и
задумано автором библиотеки: она не публикуется на PyPI, а README прямо
говорит "download the repository and place it in your project" — то есть
это классический vendoring, а не наша реализация.

Почему не переписали, как MPU_LK_API: по ТЗ (ТПО-004) для открытого API
нужно использовать существующую готовую библиотеку, а не портировать её с
нуля — в отличие от ТПО-005, где для личного кабинета явно требуется
перенос логики на Python (см. `../../lk_api`).

Лицензия — Apache License 2.0, текст сохранён в `LICENSE.md`.

`hash_salt.txt` — плейсхолдер из оригинального репозитория
(`~YOUR-HASH-SALT-HERE~`), не настоящий секрет. Нужен только конструктору
`API()` (он читает файл при инициализации, даже если соль не используется
в вызове) и реально требуется лишь для `get_students()`. Функции, которые
нужны нам по ТЗ (`get_groups`, `get_schedule`) реального значения соли не
требуют — плейсхолдера достаточно, чтобы всё остальное работало.

Обновлять эти файлы вручную, только синхронизируя с апстримом при
необходимости.
